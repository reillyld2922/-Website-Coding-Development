# -Website-Coding-Development
 Website Coding &amp; Development - FBLA Software and App Design Project

A lost and found portal for missing items, allowing for keyword searches, claim verification, auto-archives, and dates on when the item is unavailable to pick up.

Student & staff	can post found items, search and browse, submit claims, and report lost items while admins review and approve or deny claims, manage any items, and view reports on missing stuff.

Scheduled features: 
Keyword search with filters by category, location found, and date
Item posting with photo upload, description, and location
Possibly the finder or admin sets a private question only the real owner could answer, and the answer is hidden from other users
Lost item reports with automatic match suggestions based on category and keywords
Admin dashboard with pending claims, items about to expire, and usage statistics
Items unclaimed after a set ammount of days are archived automatically
Email verification
Input validation on all forms with clear enough error messages

Templates: None. All code was written by me.
